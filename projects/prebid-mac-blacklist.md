## 背景

秒针 Prebid 服务（尤其 OTT 端）原本不支持 ID/MAC 黑名单查询，原因是人力排期，非技术瓶颈。
目标：构建 MAC 黑名单查询方法论并评估是否上线。

---

## 现有 Prebid 过滤链（顺序）

1. **IP 黑名单**（秒针）
2. **威胁猎人**（第三方）
3. **IEEE 接口**（秒针）

---

## 评分机制

- 分值范围：**-1 ~ 10**
  - `-1` = 不认识（未收录）
  - `1~10` = 有风险，分越高风险等级越高
- 当前客户卡分：**9分**（过滤9分和10分的流量）

## MAC 黑名单插入方案

与 IP 黑名单并列，流量方查询时同时返回 IP 分和 ID 分，**取最高分**作为最终返回值。

### ID 黑名单生产逻辑（第一性原理）
1. **窗口**：近 30 天滚动 OTT 后验日志
2. **命中判定**：某 UUID 近 30 天触犯某规则的日志占比 ≥ X%（阈值），记为命中该规则
3. **赋分**：
   - triggered_rule_cnt = 0 → 0 分（白）
   - triggered_rule_cnt = 1 → 9 分（黑）
   - triggered_rule_cnt ≥ 2 → 10 分（黑）
   - 无后验历史 → -1 分
4. **当前阈值候选**：0.4（宽松） vs 0.5（严格）

## 测试结果汇总

### 核心数据（阈值 0.4 vs 0.5，3日均值）

| 维度 | 阈值 0.4 | 阈值 0.5 |
|------|---------|---------|
| Only ID 过滤率 | ~5.5% | ~3.8% |
| IP + ID 联合过滤率 | ~7.0% | ~5.6% |
| ID 净新增（剔除 IP overlap） | ~4.3% | ~2.9% |
| 黑名单量级（≥9分）| 1.586亿 | 1.454亿 |

### ID 与 IEEE 重合度分析 ✅ 已完成

| id 分数 | 不被 IEEE 过滤 | 被 IEEE 过滤 | 独立拦截价值 |
|---------|--------------|------------|------------|
| -1（无历史）| 25.23% | 74.77% | — |
| 0（白）| 94.18% | 5.82% | — |
| 9（黑）| 90.61% | 9.39% | ~91% |
| 10（黑）| 69.99% | 30.01% | ~70% |
| **id 黑整体** | **~89%** | **~11%** | **约 89%** |

**结论**：ID 黑名单与 IEEE 重叠极低，约 89% 独立拦截，具有高度独立的过滤价值。

## 关键判断：值不值得上线

### 核心问题 ✅ 已回答
**MAC 黑名单与 IEEE 过滤的重合度如何？**
- ✅ **重合度低**（~11%）→ **有独立增量价值，推进上线**

### 维度 1：分媒体数据
- 存在偏重，部分媒体过滤比例偏高，需业务侧确认是否可接受

### 维度 2：业务侧 + 客户接受度
- 🔄 待沟通

### 维度 3：对后验 SIVT 的影响 ⚠️ 已量化

| SIVT 口径 | 引入前 | 阈值 0.4 后 | 平均降幅 | 阈值 0.5 后 | 平均降幅 |
|-----------|-------|------------|---------|------------|---------|
| sivt_v1（全部规则）| ~10.6% | ~8.5% | ↓~2.1% | ~9.0% | ↓~1.6% |
| sivt_v2（排除夜间+新增设备）| ~3.1% | ~1.8% | ↓~1.4% | ~2.0% | ↓~1.2% |
| sivt_v3（再排除高危IP）| ~1.2% | ~0.66% | ↓~0.6% | ~0.70% | ↓~0.5% |

#### 各规则命中率变化（按降幅排序）

| 影响评级 | 规则 | 引入前 | 降幅 | 原因 |
|---------|------|-------|------|------|
| 🔴 **高** | 可疑机型曝光 | ~0.24% | ~90% | 违规强历史复发性，ID 精准覆盖 |
| 🔴 **高** | 高危 IP | ~0.14% | ~87% | 同上 |
| 🔴 **高** | byday 多地域异常 | ~0.32% | ~70% | 同上 |
| 🟡 **中** | 操作系统异常 | ~2.0% | ~40% | sivt_v2 降幅主要贡献者 |
| 🟡 **中** | 夜间曝光 | ~4.8% | ~15% | 基数最大，但大量来自正常设备 |
| 🟢 **低** | 连续曝光 | ~0.004% | ~18% | 绝对量极小 |
| 🟢 **低** | 曝光频繁 | ~0.03% | ~10% | — |
| 🟢 **低** | 曝光碰撞 | ~0.53% | ~5% | 与设备历史关联度低 |
| 🟢 **低** | 新增设备曝光 | ~3.1% | ~3% | 天然无历史记录，ID 黑名单无法覆盖 |

> **后验注意：** Prebid 提前过滤的流量从后验 SIVT 监测视角会"消失"。本次研究已做 SIVT 前后对比量化，但上线时仍需设计 A/B 对比方案。

## 未决决策

### 阈值选择：0.4 vs 0.5

| | 阈值 0.4 | 阈值 0.5 |
|--|---------|---------|
| **过滤量** | 更激进（联合过滤 7.0%） | 更保守（联合过滤 5.6%） |
| **误杀风险** | 覆盖面更广，可能误杀边缘设备 | 入黑更集中，更严格 |
| **SIVT 降幅** | sivt_v2 ↓~1.4% | sivt_v2 ↓~1.2% |
| **差异显著性** | 差异不算显著 | 差异不算显著 |

**倾向**：差异不算显著，需结合业务容忍度判断。
