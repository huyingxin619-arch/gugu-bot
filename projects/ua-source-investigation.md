# UA 来源深度排查

> **状态：** 🔴 排查中
> **发起人：** SDK 产研沟通群（张乾、王立涛、王浩阳、于长亮、于晓蕾）
> **关联：** 独立事项，与现有多维钻取/布点等项目无关

---

## 背景

芒果出现 3668 次 PC 曝光 case，需排查 UA 来源及真实性。

## 排查进展

| 时间 | 进展 | 参与人 |
|------|------|--------|
| 上午 | 确认 SDK 不主动采集 UA，header 中 UA 由系统网络框架默认带出 | 张乾、王立涛 |
| 下午 | 王浩阳梳理芒果 3668 次 PC 曝光，UA 高频含 Windows NT 等 PC 特征，需提取具体判定为 PC 的关键字段 | 王浩阳 |
| 傍晚 | 深入讨论：王立涛判断 SDK 默认 UA 被强行篡改，但签名校验未检出 | 张乾、王立涛 |
| 随后 | 找于长亮捞 rawlog 验证，与于晓蕾讨论模拟器或程序调用的可能性 | 于长亮、于晓蕾 |

## 关键发现

- **SDK 行为：** 不主动采集 UA，依赖系统网络框架默认带出
- **异常特征：** 芒果 case 中 UA 高频含 Windows NT 等 PC 特征
- **根因推断：** SDK 默认 UA 被强行篡改，但签名校验未检出（王立涛判断）
- **待验证：** rawlog 捞取验证 + 模拟器/程序调用可能性排查
