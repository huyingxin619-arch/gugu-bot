### memory_search 修复（下午）

小胡反馈 memory_search 不工作。排查根因：
- `memory index --force` 在重建索引时会创建临时 DB → 写入 meta → swap 替换主 DB
- 但 gateway 进程持有旧的 DB 连接，swap 后 gateway 看到的是被关闭的旧连接，读不到新 meta
- 重启 gateway 后 CLI 又可能触发一次 index（检测到文件变化），把 meta 又清掉了

**修复方法**：不重启 gateway，直接跑 `openclaw memory index --force`，CLI 写完 meta 后不会被覆盖，memory_search 恢复正常。

**经验落盘到 TOOLS.md**：以后碰到 memory_search 读不到内容，先 `memory index --force`，不要重启 gateway。
